# Webhook Reliability Console

An operations console for inspecting webhook deliveries, retries, idempotency keys, and dead-letter events.

## Why it matters
A production-style reference project showing clear boundaries, resilient states, accessible UI patterns, and measurable outcomes.

## Stack
TypeScript, React, Node.js, PostgreSQL-ready data model, REST APIs, Vitest-ready test seams.

## Run locally
Open  for the interactive demo. The UI is intentionally dependency-light so it can be deployed as a static preview.
